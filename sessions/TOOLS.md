# Журнал инструментов

> Только дополняется, старые записи не редактируются. Сюда попадает всё, что вы
> добавили в проект или окружение ради этой задачи: библиотеки, CLI-утилиты,
> линтеры, MCP-серверы, плагины и скиллы агента, хуки, внешние сервисы, контейнеры.
>
> Разовый вызов уже установленного инструмента сюда не пишется — он идёт
> в таблицу инструментов внутри файла сессии.
>
> Тупиковая попытка — тоже запись: поставили, не подошло, сняли. Это как раз интересно.

## Шаблон записи

```markdown
## YYYY-MM-DD · Сессия N · <инструмент> vX.Y

- **Тип:** библиотека / CLI / MCP / плагин / скилл / хук / сервис
- **Установка:** `<точная команда>`
- **Зачем:** какую задачу решает
- **Область:** проект или глобально
- **Проверка:** чем убедились, что работает
```

Удалённый или заменённый инструмент фиксируется так же — с пометкой
**удалён** / **заменён на X** и причиной.

## 2026-08-17 · Сессия 1 · pypdf 6.16.1

- **Тип:** библиотека (Python)
- **Установка:** `pip3 install --target <scratchpad>/libs pypdf`
- **Зачем:** `homework.pdf` не читался — в системе нет `pdftotext`/poppler, а само задание
  существует только в PDF. Нужно было вытащить текст, чтобы прочитать требования.
- **Область:** вне проекта, во временную папку сессии (`--target`), чтобы не ставить
  ничего глобально и не тащить зависимость в репозиторий
- **Проверка:** `PdfReader('homework.pdf')` вернул 22 страницы, текст извлечён целиком
  (38 632 символа), содержание совпало с оглавлением задания
- **Отвергнутая альтернатива:** `brew install poppler` — глобальная установка ради
  одноразового чтения одного файла


## 2026-08-17 · Сессия 3 · Playwright 1.x + Chromium

- **Тип:** библиотека / браузерный драйвер
- **Установка:** `npm install playwright && npx playwright install chromium`
  — **вне проекта**, во временной папке сессии
- **Зачем:** доказательства запуска: скриншоты на 360 и 1440, проверка клавиатуры,
  чтение консоли, прогон трёх состояний. Playwright MCP в этой сессии не подключён,
  а перезапуск сессии ради него стоил бы контекста.
- **Область:** вне репозитория. В проект не ставился намеренно: правило
  «новая зависимость — только с вопросом» относится и к dev-зависимостям,
  а инструмент проверки в `package.json` продукта не нужен.
- **Проверка:** прогон 25 проверок против дев-сервера, первый запуск дал
  2 падения (навигация стрелками), после исправления — 25/25
