## Размышления

**Корнем репозитория стало содержимое `TestTask`, а не родительская папка.**
Чек-лист задания требует, чтобы `CLAUDE.md` и `AGENTS.md` лежали в корне.
Если бы корнем была папка `ai-homework`, они оказались бы уровнем ниже,
и проверяющий, открыв репозиторий, не увидел бы их сразу. Имя удалённого
репозитория при этом совпадать с папкой не обязано.

**Два места пришлось исправить перед публикацией, иначе сдача противоречила бы
сама себе.** В `AGENTS.md` было записано «Git в проекте намеренно не ведётся»,
в README — «Git-истории нет». После появления репозитория оба утверждения
перестали быть правдой. Переписал обе формулировки: git не велся **по ходу
работы**, репозиторий заведён в конце. В README добавил прямо, что это размен
не в мою пользу — задание отдельно отмечает, что по истории коммитов видно,
как шла работа, и этой опоры у сдачи нет.

**Коммит один, намеренно.** Соблазн разложить работу на семь «логичных»
коммитов по числу сессий был, и выглядело бы это убедительнее. Но это была бы
имитация хода работы, которого в истории не существовало: все файлы легли
на диск раньше, чем появился репозиторий. Один импортный коммит честнее
и не спорит с журналом.

**Перед push проверил на секреты.** Совпадения нашлись только в материалах
занятия и оказались плейсхолдерами: `YOUR_GITHUB_PAT`, `YOUR_API_KEY`,
`$ANTHROPIC_API_KEY`. Настоящих ключей нет. `node_modules` (82 МБ из 86)
отсечён `.gitignore`, в коммит ушло 80 файлов.

**Главную проверку сделал не на своей машине, а на клоне.** Критерий задания
звучит как «проект запускается строго по README на чистой машине, без
„допишите тут своё“». Проверять это в папке, где всё уже установлено и
настроено, бессмысленно: там оно работает по определению. Поэтому склонировал
репозиторий во временную папку и прошёл по README буквально:

```
git clone → cd app → npm install → npm run build → npm run dev
```

Собралось, поднялось, и весь чек-лист из 30 проверок прошёл против клона.
Побочно вскрылась мелочь: дев-сервер клона занял порт 5176, потому что 5173
занят чужим проектом, а 5174 — рабочей копией. В README про «следующий
свободный порт» уже написано, так что расхождения с инструкцией нет.
